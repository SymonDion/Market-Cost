# Malawi Market Platform

## Run
Extract the ZIP and open `index.html`, or run `python -m http.server 8000` in this folder and open `http://localhost:8000`.

## Included
- Separate `index.html`, `style.css`, `script.js`
- Responsive dashboard, sidebar navigation, product catalogue, categories, market directory, vendors, GPS locator, calculators, analytics, Malawi information, profile, saved items and settings
- 1,500 generated sample listings: 50 product types across 30 district/market-centre entries
- Login, registration, remember-me, logout and front-end password-reset flow
- Five themes and starter Chichewa language selector

## Important limitations
This is a browser-only demonstration, not a production marketplace backend. Sample prices, previous prices, ratings, vendors, contacts, stock, update dates and some coordinates are illustrative and must be verified. Product images are representative category photos from Unsplash, not guaranteed exact product photographs. The map uses OpenStreetMap; coordinates are approximate district-centre locations. Geolocation requires permission and HTTPS or localhost. Authentication uses localStorage and stores passwords in the browser: never use real credentials. Production deployment requires a secure backend, password hashing, secure sessions, real email reset, verified data and live market/vendor integrations. No live weather, exchange-rate, market-price or news feed is connected. The Chichewa option is a starter selector, not a complete translation.
